`vite-plugin-protect-images.js` was not transforming HTML during build. Fixed by `post-build-protect.js`. The `dist/index.html` now correctly has `data-pimg="assets/images/..."` attributes.

### Bug 2 (current blocker): `protected-images.js` is not in `dist/`
`dist/index.html` contains `<script src="protected-images.js">` but the file **does not exist in `dist/`**. Vite does not copy it because:
- It is in the project root, not in a `public/` folder (Vite only auto-copies files from `public/`)
- It has no `type="module"`, so Vite warns and skips bundling it

**Effect:** The browser gets a 404 on `protected-images.js`. No script runs. All `data-pimg` attributes are never processed. No images load (except the logo, which was excluded from rewriting and keeps its direct `src`).

## Fix for Bug 2: Deliver `protected-images.js` to `dist/`

### Root cause
Vite copies files from the `public/` directory verbatim into `dist/`. The `protected-images.js` file is at the project root. Vite sees the `<script src="protected-images.js">` tag, warns it can't bundle it (no `type="module"`), and does not copy the file.

### Fix
Create a `public/` directory and move `protected-images.js` into it. Vite will then copy `public/protected-images.js` → `dist/protected-images.js` automatically on every build.

The `<script src="protected-images.js">` tag in `index.html` (and other pages) requires no change.

Steps:
1. `mkdir public/`
2. Move `protected-images.js` → `public/protected-images.js`
3. Run `npm run build` and confirm `dist/protected-images.js` exists

### All pages that need the script
All HTML pages in the project include the same `<script src="protected-images.js">` tag, so moving it to `public/` fixes all pages at once.
