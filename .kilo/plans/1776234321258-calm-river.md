# Plan: Fix Image Protection — Post-Build Script Approach

## Problem Summary

`vite-plugin-protect-images.js` is not transforming HTML during `npm run build`. Despite `enforce: "post"` and `order: "post"`, the plugin's `transformIndexHtml` handler appears to not be called (or its output is not reflected in `dist/index.html`). The root cause is likely a conflict with `ViteMinifyPlugin` in the Vite HTML transformation pipeline.

## Chosen Solution: Post-Build Script

Replace the unreliable Vite plugin approach with a post-build Node.js script (`post-build-protect.js`) that:
1. Runs after `vite build` completes
2. Reads `dist/.vite/manifest.json` to map hashed filenames → original source paths
3. Rewrites all `dist/**/*.html` files replacing `src="/assets/HASH.ext"` with `data-pimg="assets/images/original-name.ext" src=""`

This approach is simpler, more predictable, and bypasses all Vite plugin ordering issues entirely.

## Key Constraint: Path Mapping

The Netlify Function (`img.mjs`) reads images from `assets/images/` (relative to project root, bundled via `included_files` in `netlify.toml`). The built HTML contains **hashed** paths like `/assets/shakti-peya-new-JOlxPYMC.avif`.

The post-build script must use Vite's manifest (`dist/.vite/manifest.json`) to reverse-map hashed → original paths, so `data-pimg` contains the original `assets/images/foo.avif` path that the function can serve.

Vite manifest structure (example):
```json
{
  "assets/images/shakti-peya-new.avif": {
    "file": "assets/shakti-peya-new-JOlxPYMC.avif",
    ...
  }
}
```

So `manifest[originalPath].file` = hashed file → we invert this to: `hashedFile` → `originalPath`.

## Implementation Steps

### Step 1: Create `post-build-protect.js`

```js
import { readFileSync, writeFileSync } from 'fs';
import { globSync } from 'glob';

// Load Vite manifest to build hashed→original path map
const manifest = JSON.parse(readFileSync('dist/.vite/manifest.json', 'utf8'));
const hashedToOriginal = {};
for (const [originalPath, info] of Object.entries(manifest)) {
  if (info.file) {
    hashedToOriginal[info.file] = originalPath; // e.g. "assets/shakti-peya-new-JOlxPYMC.avif" → "assets/images/shakti-peya-new.avif"
  }
}

const IMAGE_EXTS = /\.(avif|webp|jpg|jpeg|png|gif)(\?[^"']*)?$/i;
const IMG_SRC_RE = /(<img\b[^>]*?)\s+src=(["'])((?:\/)?assets\/[^"']+)\2/gi;
const SOURCE_SRCSET_RE = /(<source\b[^>]*?)\s+srcset=(["'])((?:\/)?assets\/[^"']+)\2/gi;
const BG_STYLE_RE = /(<[^>]+\bstyle=(["'])[^"']*?)url\((['"]?)((?:\/)?assets\/[^)"']+)\3\)/gi;

function normalizePath(p) {
  return p.startsWith('/') ? p.slice(1) : p;
}

function resolveOriginalPath(p) {
  const normalized = normalizePath(p); // e.g. "assets/shakti-peya-new-JOlxPYMC.avif"
  return hashedToOriginal[normalized] || normalized; // fall back to normalized if not in manifest
}

function isProtectedImage(p) {
  return !(/\.mp4$/i.test(p)) && IMAGE_EXTS.test(p);
}

function isLogoImg(prefix) {
  const lower = prefix.toLowerCase();
  return lower.includes('alt="sampriti logo"') || lower.includes("alt='sampriti logo'");
}

const htmlFiles = globSync('dist/**/*.html');
for (const file of htmlFiles) {
  let html = readFileSync(file, 'utf8');

  html = html.replace(IMG_SRC_RE, (match, prefix, quote, path) => {
    if (!isProtectedImage(path) || isLogoImg(prefix)) return match;
    const original = resolveOriginalPath(path);
    return `${prefix} data-pimg="${original}" src=""`;
  });

  html = html.replace(SOURCE_SRCSET_RE, (match, prefix, quote, path) => {
    if (!isProtectedImage(path)) return match;
    if (/type=(["'])video/i.test(prefix)) return match;
    const original = resolveOriginalPath(path);
    return `${prefix} data-psrcset="${original}"`;
  });

  html = html.replace(BG_STYLE_RE, (match, prefix, styleQuote, urlQuote, path) => {
    if (!isProtectedImage(path)) return match;
    const original = resolveOriginalPath(path);
    const withoutUrl = match.replace(`url(${urlQuote}${path}${urlQuote})`, 'url()');
    return withoutUrl.replace(/<(\w+)/, `<$1 data-pbg="${original}"`);
  });

  writeFileSync(file, html);
  console.log(`[protect-images] Protected: ${file}`);
}
console.log('[protect-images] Done.');
```

**Note:** Vite must be configured to emit the manifest. Add `build.manifest: true` to `vite.config.js`.

### Step 2: Update `vite.config.js`

Add `manifest: true` to `build` options so `dist/.vite/manifest.json` is generated:

```js
build: {
  outDir: 'dist',
  emptyOutDir: true,
  manifest: true,  // ← add this
  rollupOptions: { input },
},
```

### Step 3: Update `package.json` build script

```json
"build": "vite build && node post-build-protect.js"
```

### Step 4: Remove (or disable) the Vite plugin

Remove `protectImagesPlugin()` from `vite.config.js` plugins array to avoid any partial/conflicting transformation. The file `vite-plugin-protect-images.js` can be kept for reference but won't be used.

### Step 5: Verify

After `npm run build`:
- Check `dist/index.html` has `data-pimg="assets/images/foo.avif"` attributes and `src=""`
- Check no plain `src="/assets/HASH.avif"` remain on protected images
- Logo img should still have its original `src`
